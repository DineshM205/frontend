Task 1 — Setup a New Project
Create a new HTML file and link Bootstrap via CDN.
Add a <div class="container"> and confirm styling works.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">

    <title>Bootstrap Project</title>

    <!-- Bootstrap CDN -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>

    <!-- Container -->
    <div class="container">
        <h1>Hello Bootstrap 👋</h1>
        <p>This is inside a Bootstrap container.</p>
    </div>

</body>
</html>
Task 2 — Typography & Spacing
Add headings, paragraphs, and apply text utilities like .text-center, .text-primary.
Use spacing utilities (p-, m-) to style sections.
<body>

    <div class="container mt-5">

        <!-- Heading -->
        <h1 class="text-center text-primary mb-4">
            Welcome to My Page
        </h1>

        <!-- Paragraph -->
        <p class="text-center mb-3">
            This is a simple Bootstrap typography example.
        </p>

        <!-- Section with spacing -->
        <div class="p-4 bg-light mt-4">
            <h3 class="text-success">Section Title</h3>
            <p>
                This section uses padding (p-4) and margin (mt-4).
            </p>
        </div>

        <!-- Another section -->
        <div class="p-3 mt-3 bg-secondary text-white">
            <h4>Another Section</h4>
            <p class="mb-0">
                This shows spacing and background color.
            </p>
        </div>

    </div>

</body>
